# Superstore Sales & Profitability Dashboard

## Overview
An interactive Tableau dashboard analyzing sales and profitability 
using the Superstore dataset.

## Tools Used
Tableau, Excel

## Key Insights
- California, Texas, and New York are the top-performing states by sales
- Sales spike every holiday season, but profit doesn't grow at the same pace
- The "Tables" sub-category is losing money despite steady sales volume
- Customer segment drives more sales than Corporate and Home Office combined
